# Architecture Decision Records

One file per decision, numbered `NNNN-short-title.md`, never renumbered.
A superseded record stays in place with its status changed to
`Superseded by NNNN`.

Each record has these sections:

- **Status**: `Proposed`, `Accepted`, `Rejected` or `Superseded by NNNN`
- **Context**: the problem and the forces at play, citing code where relevant
- **Decision**: what we do
- **Consequences**: what gets easier, what gets harder, and the risks
- **Alternatives**: options considered and why they lost
