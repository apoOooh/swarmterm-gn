# Swarmterm GN 1.10.0

- **Voice listening pill:** while you dictate with buzzkey, the pane the text
  will land in shows a "Listening…" pill with a Stop button. Stop discards the
  dictation. Needs buzzkey with protocol negotiation (1.9.1+bk.3 or later);
  older buzzkey versions keep working without the pill. Changing auto-Enter
  in **Settings → Voice** no longer cancels a dictation in progress.
- **Add-account wizard:** **Settings → Accounts → Add account** creates a
  Claude Code or Codex profile and opens its login in one step. Account cards
  show whether a profile is logged in.

See `CHANGELOG.md` for the full list.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
