# Swarmterm GN 1.19.0

- **Account per workspace:** the account you pick for Claude Code or Codex in
  the workspace composer (a fixed profile or round robin) now also applies to
  panes you split off later, and saved workspaces remember it. Without a
  choice, a split pane uses the account of the pane it was split from.
- **Fix: switching account in a new pane:** changing the account of a pane
  that has not had a turn yet (such as a pane just split off) used to fail
  and stay on Default. It now restarts the pane on the chosen account.
- **Pane highlight on by default:** Settings → Appearance → *Highlight panes
  by agent state* is now on unless you switched it off yourself.
- **Building from source without LLVM:** the built-in speech engine is an
  optional build feature. `npm run tauri:dev:no-speech` and
  `npm run test:rust:no-speech` work without LLVM and CMake. The installer
  still includes built-in speech recognition.

See `CHANGELOG.md` for the full list.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
