# Swarmterm GN 1.14.0

- **Workspace defaults:** the new-workspace composer now starts from your own
  defaults — folder, number of terminals, AI agents and their accounts,
  worktree isolation and *Split opens*. Click **Save as default** in the
  composer, or edit them (or reset them) under **Settings → Workspaces**.
  Agents that aren't installed are left out when defaults are applied.
- **Workspace templates:** **Save as template…** stores the composer's
  choices under a name; pick a template from the new **Template** list when
  creating a workspace. Add, edit, duplicate and delete templates under
  **Settings → Workspaces**.
- **Peek the right panel:** while the right panel (Preview, Git, War Room) is
  closed, rest the mouse on the right edge of the window to slide it in over
  the workspace. The pin button docks it; Preview needs the docked panel. Turn
  it off under **Settings → Appearance → Peek right panel on right edge**.
- **Tidier composer:** only installed agents are listed, the layout preview
  is smaller and the agent legend below it is gone.

See `CHANGELOG.md` for the full list.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
