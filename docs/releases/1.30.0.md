# Swarmterm GN 1.30.0

Feature release: custom status line, team packages and Codex/dictation fixes.

- **Custom status line:** a new **Custom** template for Claude Code and Codex.
  Switch each part on or off and change the order; Codex offers only items
  Swarmterm has tested with its version.
- **Team package:** Settings → Terminal → Team package fetches a team's rules,
  skills and command guards for agent CLIs from an https Git URL or a local
  folder, and installs, updates, removes or checks them with the package's own
  install script. Every change shows a preview and runs only after you confirm
  it; the package runs from a copy in Swarmterm's own folder. Lockable with the
  policy value `DisableTeamPackage`; not available in the Corp edition.
- **Codex panes:** always start with `--no-daemon` when Codex supports it —
  also on a busy machine, with a very long PATH, with `codex.exe`/`.cmd` start
  lines or leading blanks. If the version check still gets no answer, the bell
  says so.
- **Dictation into choice dialogs:** a second dictation into Claude Code's
  "Type something" field is appended instead of refused, also for long
  answers that wrap.
