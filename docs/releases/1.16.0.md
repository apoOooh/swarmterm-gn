# Swarmterm GN 1.16.0

- **Spoken announcements (opt-in):** Settings → Voice → "Speak announcements"
  lets Swarmterm say when an agent finished or waits for input, using an
  installed Windows voice. Typing, focusing the pane, dictating or
  Ctrl+Shift+M stops it.
- **Command routines:** a routine can run a shell command on a schedule
  instead of an agent, in the background, with a time limit. Only failures
  are reported in the bell.
- **Multi-line prompts:** Shift+Enter in an agent pane inserts a line break
  instead of submitting the prompt.

See `CHANGELOG.md` for the full list.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
