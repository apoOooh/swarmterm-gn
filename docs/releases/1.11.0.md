# Swarmterm GN 1.11.0

- **Account profiles behave like your Default account:** Claude Code panes on
  a named profile now get your status line, your user-level MCP servers, your
  hooks and your `permissions.deny`/`ask` rules from the Default account. A
  guard such as a data-masking hook therefore also protects sessions under a
  profile. `permissions.allow` is never copied, and the profile's own entries
  stay untouched.
- **Account usage:** the last known usage survives a restart and shows its
  age; Codex usage refreshes after each turn and every minute while
  **Settings → Accounts** is open.
- **Status line switch:** turning Swarmterm's Claude status line on or off no
  longer fails when your Default account uses its own status line.

See `CHANGELOG.md` for the full list.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
