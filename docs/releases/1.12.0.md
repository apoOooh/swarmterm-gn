# Swarmterm GN 1.12.0

- **Customizable title bar:** a new **Settings → Title bar** page lists every
  pane-header control. Drag them (or use the arrow buttons) into any order and
  set each one to **Core** (always in the bar), **Can hide** (moves out when
  the pane gets narrow), **⋯ only** (never in the bar, always in the `⋯` row)
  or **Off** (not shown at all). The title always stays; maximize and ✕ stay
  at the right. **Reset to defaults** restores the original layout.
- **Narrow panes keep their key controls:** when a pane is too narrow, the
  agent, title, folder, maximize and ✕ stay in the header and the rest moves
  behind a `⋯` button. Hover the header to drop them in a second row, or click
  `⋯` to keep that row open.
- **Maximized panes are easy to spot:** a maximized pane gets a violet border
  and a violet restore button showing how many panes it hides; the sidebar
  marks it and dims the hidden panes.
- **Even out panes:** double-click a split separator or corner handle to give
  the panes equal size.
- **Claude Code fullscreen stays on:** closing a pane now lets agents shut down
  cleanly before their processes are stopped, so Claude Code no longer turns
  its fullscreen mode off machine-wide after a pane was closed.
- **Performance:** terminal output is batched, sidebar resizing is smoother,
  and blocking work no longer runs on the UI thread.

See `CHANGELOG.md` for the full list.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
