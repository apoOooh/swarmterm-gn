# Swarmterm GN 1.17.0

- **Spoken replies for Claude Code (opt-in):** with Settings → Voice →
  "Allow excerpts" on, Swarmterm says Claude's own short summary of each
  answer instead of "fertig", also for the pane you are looking at. Failed
  and Esc-stopped turns are said in the same tone and shown in the bell.
  The text is read from the agent's session file, kept in memory only and
  never sent anywhere.
- **buzzkey update notice:** with buzzkey connected, Swarmterm offers newer
  signed buzzkey releases ("Update now" / "Later"), optionally automatically.
- **Agent-state highlight (opt-in):** Settings → Appearance frames each agent
  pane in its state colour — working, waiting long, blocked, finished.
- **Better built-in speech models:** quantised Small to Large v3 models with
  a recommendation for this PC; new installs default to Small q5.
- Fixes: a late Stop of an earlier prompt no longer ends the current turn;
  Esc in the pane header's ⋯ row keeps the keyboard focus on ⋯.

See `CHANGELOG.md` for the full list.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
