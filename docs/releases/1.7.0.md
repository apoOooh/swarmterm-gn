# Swarmterm GN 1.7.0

- **Prompt library:** save prompts on this machine and send one to a running
  Claude Code or Codex pane, or start it in a new pane next to the focused
  one, optionally in a fresh git worktree. Delivery to a running pane waits
  while you type or the agent works and is sent once.
- **Conversation view:** a read-only view of a Claude Code or Codex pane's
  session, read from the CLI's own session file.
- **Account usage in the handoff:** Claude Code's 5-hour and 7-day rate
  limits are kept per account profile and shown for the handoff target.
  Codex usage stays "unknown" (no structured source).

See `CHANGELOG.md` for the full list.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
