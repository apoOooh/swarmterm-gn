# Swarmterm GN 1.15.0

- **Built-in dictation:** Settings → Voice downloads a checksum-verified
  Whisper model and enables local speech input without buzzkey.
  Ctrl+Shift+Space or the pane-header microphone starts and stops; the text
  arrives as a draft in the pane that had the keyboard. Runs on the CPU.
- **buzzkey from Settings:** install and control the buzzkey companion from
  Settings → Voice. Only signed releases are installed, verified before use.
- **Shared sessions across subscriptions:** resume a conversation under a
  different account.
- **Startup workspaces:** pin saved workspaces to open on startup, in order.
- **Status announcements (opt-in):** a dictation app can be told when an
  agent finished or needs input in a pane you are not watching.
- **Floating panes** stay put when side panels toggle and move by their
  header; docked pane headers can be dragged again.

See `CHANGELOG.md` for the full list.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
