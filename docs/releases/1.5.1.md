# Swarmterm GN 1.5.1

- **Pane drawer:** park a terminal with the archive button or Ctrl+Shift+D.
  Its shell, scrollback and preview keep running; the sidebar lists parked
  panes under Drawer and one click restores them to their original slot.
- **Default AI provider:** Settings > Terminal sets which agent new splits
  open; a workspace can override it. Alt+click a split button for a plain
  shell. An uninstalled agent falls back to a shell.
- **Launch modes per provider:** Claude Code no longer always starts with
  bypassed permissions. Choose Default, Accept edits, Plan or Bypass
  permissions as each provider's default; running panes keep their mode.
- **Drag to split and snap layouts:** drop a pane on another pane's edge to
  split beside it, or on a snap bar preset (side by side, stacked, grid,
  main-left, main-top) to rebuild the layout.
- **Paste screenshots:** Ctrl+V with an image on the clipboard pastes it into
  Claude Code and Codex panes as an attached image.
- **Folder picker:** Choose folder starts in the workspace folder.

1.5.1 replaces the unpublished 1.5.0 (its release checks failed on two
outdated browser tests); the contents are the same.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
