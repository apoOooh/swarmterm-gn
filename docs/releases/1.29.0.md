# Swarmterm GN 1.29.0

Status line release: templates with a live preview for Claude Code and Codex,
plus more reliable media detection.

- **Status line templates:** choose Compact, Extended or Detailed (or Off)
  under the new **Settings → Status line**, with a live preview drawn by the
  same code as the real line. Extended adds the effort, a context bar, the git
  branch and the 5-hour / 7-day limits; Detailed adds cost, prompt cache,
  subagents and token bars (estimates marked `≈`). The setup assistant has a
  new Status line step with the templates.
- **Colours:** Subtle (near-monochrome), App theme (follows the active
  Swarmterm theme, with a Vibrance slider; warnings stay coloured) and High
  contrast (the terminal's 16 basic colours).
- **Fits the pane:** the line wraps by segment to the pane width instead of
  being cut off; on narrow panes the branch, cache and subagents are left
  out first.
- **Codex:** the same three templates set Codex's built-in status line
  (`[tui] status_line`) in every Codex profile. Swarmterm remembers what was
  there before, never overwrites a list you changed yourself, and **Not
  managed** restores your previous setting.
- **Media:** images and videos that agents and their subagents open with
  Claude's Read/Write tools now reach the Media strip, also when the path
  never appears on screen; a file overwritten in place shows up again with
  its new thumbnail.
- **Worktrees:** a folder that is only a subfolder of a larger repository
  gets no worktree isolation, so panes start where you chose.
