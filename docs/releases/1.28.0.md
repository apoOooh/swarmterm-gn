# Swarmterm GN 1.28.0

First-start release: a setup assistant for new installations, hooks and MCP
without Git Bash or a fixed port, and prompts blocked by data-shield come
back masked.

- **Setup assistant:** a new installation opens a four-step assistant:
  tools and agents (what is missing, why, the vendor link and an install
  command to copy; Swarmterm installs nothing itself), sign-in, voice and a
  first workspace. It can be skipped and run again under **Settings →
  Setup**. Voice dictation is off by default on a new installation;
  existing installations keep their setting.
- **Hooks without Git Bash:** with Claude Code 2.1.139 or newer, Claude
  Code starts `swarmterm.exe --hook` directly instead of through a shell.
  Older Claude Code versions keep the previous entry; the entries switch
  over by themselves when Claude Code is updated. The status line still
  needs Git Bash.
- **MCP as a local helper:** Claude Code and Codex now start
  `swarmterm.exe --mcp-stdio`, which forwards to the Swarmterm the pane runs
  in. Outside Swarmterm it offers no tools instead of a failed server.
- **Prompts blocked by data-shield:** a prompt data-shield's guard blocks
  is put back masked into the same pane and sent, only after your own Enter
  in that pane and while Claude shows the restored draft. Choose *put back
  and send*, *put back, I press Enter* or *do nothing* under **Settings →
  Terminal → Agent safety**; administrators can lock it.
- **War Room pane tags:** members and messages show the pane's number, so
  several panes with the same title stay apart.
- **Fewer freezes:** file previews and several commands no longer run on
  the UI thread; images and documents served whole are limited to 32 MB. A
  watchdog logs window stalls locally; an opt-in hang dump
  (`DisableHangDumps`, locked in Corp) helps analyse them.

See `CHANGELOG.md` for the full list.

## Upgrade notes

- The Swarmterm MCP entry in Claude Code and Codex is replaced at the first
  start, but only when it is exactly the entry Swarmterm wrote. Going back to
  1.27.0 or older: switch the Swarmterm server off under **Settings → MCP**
  before uninstalling this version and on again in the older one.
- New policy values: `DisablePromptResubmit`, `DisablePromptResubmitSend`
  and `DisableHangDumps` (ADMX/ADML in `docs/admin/`).

## Download

Two Windows x64 setup executables are attached to this release:

- `Swarmterm.GN_1.28.0_x64-setup.exe`: Standard edition, per-user install.
- `Swarmterm.GN.Corp_1.28.0_x64-setup.exe`: Corp edition, per-machine install
  (needs administrator rights).

The Microsoft WebView2 Runtime is required.

Verify the download in PowerShell before installing:

    Get-FileHash -Algorithm SHA256 .\Swarmterm.GN_1.28.0_x64-setup.exe
    # must match the line in SHA256SUMS.txt
    gh attestation verify .\Swarmterm.GN_1.28.0_x64-setup.exe --repo apoOooh/swarmterm-gn
    # proves it was built by this repository's release workflow

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. The app never updates itself. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
