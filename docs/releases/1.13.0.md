# Swarmterm GN 1.13.0

- **Peek the hidden sidebar:** with the sidebar hidden, rest the mouse on the
  left edge of the window to slide it in over the workspace. Turn it off under
  **Settings → Appearance → Peek sidebar on left edge**.
- **App problems in the bell:** the notification bell now tells you when the
  MCP server stopped, when voice input failed (and clears once it recovers),
  and when a pane stopped reading input so a paste was dropped — with the
  reason.
- **Big pastes:** pasting a very large block into an idle pane is no longer
  rejected.
- **Git:** the changed-files list shows renamed files correctly and handles
  paths with spaces or non-ASCII characters, so their diffs open again.
- **Safer worktree clearing:** clearing a worktree now refuses to delete a
  branch that is not the one checked out there, and clearing a worktree on a
  detached HEAD works.
- **War Room limits:** messages are limited to 64k characters and an unread
  inbox keeps at most 200 messages; the reader is told how many older ones
  were dropped.
- **Reliability:** voice input and the MCP server recover from or report
  failures instead of stopping silently; Codex support is detected at startup.
- **Performance:** the sidebar and the file tree re-render far less while
  agents stream output, and opening large folders no longer stalls the UI.
- **Fixes:** event listeners are cleaned up when panes and dialogs close,
  dialogs no longer show results of an earlier request, and closed panes no
  longer leave titles, previews or War Room members behind.

See `CHANGELOG.md` for the full list.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
