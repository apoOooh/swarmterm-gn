# Swarmterm GN 1.4.0

- **Saved workspaces:** save up to 24 workspaces and reopen their pane layouts,
  folders, shells, agents, launch modes and worktree bindings from Welcome.
  Claude Code and Codex panes restore their own conversations and account
  profiles. Missing folders, sessions or CLIs show a fallback notice.
- **Agent accounts:** manage separate Claude Code and Codex profiles, select
  an account per pane or rotate accounts when composing a workspace.
  Credentials remain in the agent CLI's configuration; complete login there.
- **Custom shortcuts and workspace macros:** customize app shortcuts with
  conflict detection, or save reusable pane layouts without storing shell
  commands. Macros validate their account and agent requirements before opening
  workspaces.
- **MCP catalogue:** add reviewed server definitions through Settings to a
  default or named account. Existing configuration is preserved and conflicts
  are shown. Complete authentication in the agent CLI; servers are not started
  automatically, and the Playwright definition uses headless mode.
- **Performance:** spread new terminal initialization across animation frames,
  move terminal creation and account configuration off the UI thread, combine
  concurrent metadata refreshes, and wait for folder typing to settle before
  scanning projects. Workspace macros share a single fresh metadata probe.
- **Terminal reliability:** preserve the latest size when a terminal finishes
  connecting and clean up delayed starts when panes close or accounts change.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
