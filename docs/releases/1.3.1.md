# Swarmterm GN 1.3.1

- **Files drag & drop:** drag files or folders onto a terminal to insert
  their quoted paths; Claude Code panes get relative `@` mentions. Dragging
  shows a copy/move cursor; Ctrl copies into a folder, Esc cancels. File tabs
  drag between panes.
- **Path links in terminals:** Ctrl+click a path to open it and select it in
  Files; Ctrl+drag it onto another pane to insert it. File and folder names in
  a PowerShell `dir` listing are links too.
- **SVG and HTML preview** with Editor / Split / Preview modes, updated live.
- **Maximize a pane** (header button, double-click or Ctrl+Shift+Enter).
- **Ctrl+Shift+Backspace** clears the pending input line of the focused terminal.
- **Sidebar "Auto" layout** (new default): Files fills the remaining height.
- **Codex launch modes** (Auto, Safe, YOLO) and "Resume previous chat…".
- Fixes: last terminal row cut off after resizing; Ctrl+click on absolute
  Windows paths opening externally; a stray `^[[I` above the Claude Code
  banner when focus moved during startup.

1.3.1 replaces the unpublished 1.3.0 (its release checks failed on two
outdated browser tests); the contents are the same.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
