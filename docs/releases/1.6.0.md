# Swarmterm GN 1.6.0

- **Account and agent handoff:** write an editable handoff brief from any
  pane, then continue the work in a new Claude Code or Codex pane on another
  account profile. The brief is sent once, only after the new agent runs and
  you confirm; the old pane keeps running.
- **In-app folder picker** with pinned favorites, recent and saved-workspace
  folders, type-to-filter and a Windows dialog fallback.
- **Layout:** floating panes, corner resize and **Tidy layout**, which sizes
  every row and column of panes equally.
- **Notification center** in the title bar for panes that need input, exits,
  held War Room deliveries and handoff outcomes.
- **War Room:** agents (Claude Code, Codex, OpenCode) connect without setup,
  read messages are no longer lost, and Settings > MCP has an on/off switch
  per agent and account.
- **Fixes:** fast resizing no longer scrambles agent output, shells that exit
  end their pane, and several handoff and folder-picker focus issues are
  resolved.

See `CHANGELOG.md` for the full list.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
