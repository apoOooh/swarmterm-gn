# Swarmterm GN 1.24.0

- **War Room:** messages now reach agent panes whose status line keeps
  repainting, and are held while an agent's input box has an unsent draft; the
  ⏸ badge says why, with "Deliver now". Type `@` to mention peers: a message
  with mentions goes only to them, `@everyone` to the whole room.
- **Performance:** one pane's slow resize, creation or flood no longer stalls
  the others, workspaces open their panes in parallel, the explorer stays
  current during file watcher storms, and processes started by agents run at
  below-normal priority (Settings → Terminal, per-workspace opt-out).
- **Rendering:** every pane gets a WebGL renderer again (up to 16), so
  switching workspaces is instant; heavy floods fall back to the DOM renderer
  while many panes are visible.
- **MCP:** a restarted app waits briefly for its previous port, so reattached
  panes keep their MCP connection.
- **Media:** wrapped table paths are detected, the thumbnail strip scrolls and
  keeps 50 items, and pan works at any zoom.

See `CHANGELOG.md` for the full list.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
