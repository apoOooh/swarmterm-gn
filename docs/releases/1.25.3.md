# Swarmterm GN 1.25.3

This is the first published 1.25 release. 1.25.0, 1.25.1 and 1.25.2 were tagged but not published, because their release checks failed (Rust formatting and one Clippy lint, then tests that could not find `ping` and `node` on the CI runner).

- **Process priority:** agent shells, builds and tools can no longer run at
  Normal priority and freeze Windows. Each pane's processes are held below
  Normal by a Windows Job Object from the moment they start; they cannot
  raise themselves back or escape, and orphans stay covered. This replaces
  the 1.24.2 watcher, which could be escaped.
- **Settings → Terminal → Process priority:** Strict (default, whole pane),
  Agent stays Normal, or Off; pane and build levels (Below normal or Low);
  and an optional CPU cap per pane. The old setting is migrated.
- **Agent detection:** agents installed through npm are recognised by their
  command line, so what they start is lowered too.
- **Older host:** if an older terminal host is still running after the update,
  new panes run in the app with limits enforced, and Settings says why.

Processes Windows starts on an agent's behalf (WMI, Task Scheduler, services,
COM, Explorer) are outside any pane and not covered.

See `CHANGELOG.md` for the full list.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
