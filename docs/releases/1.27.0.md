# Swarmterm GN 1.27.0

Terminal host release: panes now live in a separate `swarmterm-host.exe`
by default, so they can outlive a quit, a crash or an update.

- **Terminal host on by default:** new panes run in `swarmterm-host.exe`.
  If you turned the host off before, it stays off. Without a usable host,
  panes still open inside Swarmterm and **Settings → Terminal** says why.
- **Keep terminals running on quit:** while panes run in the host, Quit asks
  *Keep terminals running?*. **Close all** (default) closes them as before,
  **Keep running** leaves them running and the next start takes them over.
  Without hosted panes Quit does not ask.
- **Updates never replace a running host:** the installer ships
  `swarmterm-host.exe`; Swarmterm copies it to a folder per build under
  `%LOCALAPPDATA%\<app id>\host\`, checks its hash before each start and runs
  it from there. After an update, panes on the previous build's host stay
  there and can be reopened; new panes go to the new host. An old host
  disconnects once it holds no pane, and its folder is removed at the next
  start.
- **Voice: Codex turns end exactly:** Swarmterm registers Codex's `Stop` and
  `Interrupt` hooks next to the session capture. A pause in the middle of a
  turn is no longer announced as done, Esc is said as interrupted, and with
  **Allow excerpts** the agent's reply is spoken for Codex too.
- **Terminal links:** a relative file path that does not exist below the
  pane's folder is also looked up in the absolute folders printed nearby, so
  Ctrl+click works on paths a tool printed relative to its own folder.

See `CHANGELOG.md` for the full list.

## Upgrade notes

- Codex asks for one more `/hooks` review, for the new `Stop` and
  `Interrupt` hooks.
- To keep panes inside the app as before, turn the host off under
  **Settings → Terminal**.

## Download

Two Windows x64 setup executables are attached to this release:

- `Swarmterm.GN_1.27.0_x64-setup.exe`: Standard edition, per-user install.
- `Swarmterm.GN.Corp_1.27.0_x64-setup.exe`: Corp edition, per-machine install
  (needs administrator rights).

The Microsoft WebView2 Runtime is required.

Verify the download in PowerShell before installing:

    Get-FileHash -Algorithm SHA256 .\Swarmterm.GN_1.27.0_x64-setup.exe
    # must match the line in SHA256SUMS.txt
    gh attestation verify .\Swarmterm.GN_1.27.0_x64-setup.exe --repo apoOooh/swarmterm-gn
    # proves it was built by this repository's release workflow

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. The app never updates itself. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
