# Swarmterm GN 1.29.1

Security and dictation fix release.

- **Security — local MCP server:** every request to the in-app MCP server now
  needs the token of a live pane, including the `initialize` and `tools/list`
  handshake. Previously only tool calls were checked, so any local process
  could read the tool list and server instructions. All loopback routes also
  refuse a `Host` other than `127.0.0.1`, `localhost` or `[::1]` with the
  server's port, which blocks web pages using DNS rebinding, and the MCP
  endpoint refuses browser requests. Agents started in Swarmterm panes are
  not affected.
- **Dictation into choice dialogs:** dictated text now lands in the empty
  "Type something" field of a Claude Code choice dialog instead of being
  refused. Permission prompts stay locked and nothing is confirmed
  automatically.

## Upgrade note

A pane that has survived in the terminal host since a build before per-pane
session secrets still identifies itself with its pane id. Its agent now shows
`mcp offline` until the pane is restarted; restarting the pane (or the agent
in it) restores the connection.
