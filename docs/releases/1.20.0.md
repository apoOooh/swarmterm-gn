# Swarmterm GN 1.20.0

- **Pane identity:** give a pane an icon (from a built-in set or any emoji),
  a name and a color so you can tell at a glance who does what. Click the
  small smiley left of a pane's title, or right-click the pane → *Set
  identity…*. The header shows the name next to the agent's own title, and
  the icon also appears in the sidebar list and on the pane's War Room
  avatar. Identities are kept with saved workspaces and never restart a pane.
- **Name a workspace when you create it:** the workspace composer has an
  optional *Name* field. Left blank, the workspace is still named after its
  folder.
- **Fix: renaming a workspace:** when a file was open in the focused pane,
  clicking inside the rename field could move the keyboard to the editor and
  save a half-typed name, so capitals at the start or end seemed impossible.
  The rename field now keeps the keyboard until you press Enter or Escape.

See `CHANGELOG.md` for the full list.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
