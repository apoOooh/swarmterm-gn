# Swarmterm GN 1.2.0

- Markdown files open rendered by default, in a centred reading view styled
  after MarkText. **Settings → Files → Open Markdown as** switches the default
  to Split or Source; the toolbar still switches each file individually.
- **Open in MarkText** in the file toolbar and the explorer context menu hands
  a `.md` file to the external [MarkText](https://www.marktext.cc/) app. Unsaved
  edits are saved first. The install is auto-detected; a different path can be
  set under **Settings → Files → MarkText** (only `marktext.exe` is accepted).
- The release workflow hashes the published installer filename in
  `SHA256SUMS.txt`.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
