# Swarmterm GN 1.14.2

- **Folders under an open file explorer can be renamed again:** while the
  Files tree was open, Swarmterm held one open watch handle per folder of the
  project. Windows refuses to rename or move a folder while a handle is open
  anywhere below it, so renames failed with "Access denied" (WinError 5) for
  git, npm, pip, cargo, build scripts and editors that unpack into a temporary
  folder and rename it. Live refresh now uses a single watch on the explorer's
  root folder, so everything below it renames and moves freely. Only the root
  folder itself stays locked while its tree is open. During very heavy file
  churn the tree re-reads its open folders once things go quiet.

See `CHANGELOG.md` for the full list.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
