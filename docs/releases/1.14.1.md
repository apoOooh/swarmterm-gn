# Swarmterm GN 1.14.1

- **Claude Code hooks no longer break after a development build:** a
  development build of Swarmterm (`npm run tauri dev`) used to repoint the
  `swarmterm --hook` entries and the status line in `~/.claude/settings.json`
  at its own `target/debug` binary. Once that checkout was deleted, every
  Claude Code tool call reported `swarmterm.exe: No such file or directory`.
  A development build now leaves these entries to an installed Swarmterm that
  still exists. Starting the installed app still repairs entries that point
  at a missing binary. If you already see the error, update, then restart
  Swarmterm and your Claude sessions.

See `CHANGELOG.md` for the full list.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
