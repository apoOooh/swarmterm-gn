# Swarmterm GN 1.1.0

The first Windows release of the GN fork, based on Swarmterm 1.0.4.

- All seven Astera themes: Vega, Orion, Umbra, Aurora, Antares, Quasar and Sirius,
  including bundled fonts, theme previews and live terminal palette changes.
- A resizable Files sidebar following the selected terminal's project or
  worktree, with Git badges, virtualized browsing and file operations.
- Native file clipboard, drag-and-drop, undo and bounded deletion history.
- Shared editor tabs, find/replace, CRLF/BOM preservation, dirty-close guards
  and external-change conflict handling.
- Sanitized Markdown previews, split scrolling, heading links and search,
  plus image/video previews with stable-change reload.
- Run supported files in a dedicated shell without replacing an existing PTY.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.

Text editing supports UTF-8 files up to 1 MiB. Workspaces do not survive an
application restart. Native clipboard, tray and codec interactions still need
the documented manual desktop smoke checks. See the user guide and migration
notes in the tagged source for details and source attribution.
