# Swarmterm GN 1.23.0

- **Media panel:** inspect images and videos your agents produce, from any
  folder, in a new right-panel tab. Wheel zoom and pan, a thumbnail strip, a
  pane badge for media paths printed in a pane, an optional auto-show popup and
  opt-in clipboard capture. Drag a thumbnail into a pane to insert its path
  like Ctrl+V, and mark images up with pen, arrow and shapes before sending
  them to an agent. The preview is user-side only: agents get no tool and no
  access through it.
- **Performance and memory:** output flow control and raw-byte output keep
  floods from growing WebView memory, panes hold a WebGL context only while
  visible, the file watcher handles event storms with one rescan, and
  background re-renders are reduced. New Settings → Terminal → *Scrollback*.
- **War Room:** joining, moving, leaving or deleting a room wakes pending
  `wait_peer` calls at once.

See `CHANGELOG.md` for the full list.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
