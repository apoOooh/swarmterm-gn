# Swarmterm GN 1.9.0

- **Voice dictation:** a local dictation app (buzzkey) can type what you say
  into the pane that had the keyboard when you started speaking — even if you
  click another pane while it transcribes. Text arrives as a draft and is
  never redirected; a pane waiting on a permission prompt gets nothing, and
  plain shells receive a single line. The endpoint is a named pipe for your
  Windows user only, with a fresh key per launch. **Settings → Voice**
  switches it off or allows auto-Enter (off by default).

See `CHANGELOG.md` for the full list.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
