# Swarmterm GN 1.21.0

- **Tinted top bar:** a pane identity can now color the pane's whole header
  bar. Pick a color in the identity dialog and tick *Tint the top bar*; the
  bar gets a light wash and a full-color bottom edge, so the pane stands out
  from across the screen.
- **Every Lucide icon, searchable:** the identity icon grid scrolls through
  all ~2,000 Lucide icons (suggestions first, then A–Z), and the search box
  filters it by name — "arrow up" finds every up arrow. Enter takes the best
  match. Icons load as you scroll, so the app does not get heavier.
- **20 identity colors:** teal, cyan, blue, indigo, purple, pink, lime, gold,
  brown and slate join the original ten.
- **Click the name to edit:** in a pane header, clicking the identity name
  opens the identity dialog, just like clicking its icon.

See `CHANGELOG.md` for the full list.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
