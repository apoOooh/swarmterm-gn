# Swarmterm GN 1.18.0

- **Pane numbers and names:** every pane shows its number in the header and
  the navbar; double-click the title to rename it. Names are kept with saved
  workspaces.
- **Spoken pane addressing:** with a buzzkey release that supports it, a
  dictation can name its target pane ("pane 2", a pane name or title) instead
  of going to the focused pane.
- **Terminal host groundwork:** the code for running panes in a separate
  `swarmterm-host.exe` that survives an app crash is included, but the
  installer does not ship the host yet. The setting in Settings → Terminal
  stays off by default and, when switched on, keeps panes inside Swarmterm
  and says why. Shipping the host follows in a later release.
- Fixes: the explorer forgets expanded folders that vanished from disk;
  settings toggle switches no longer overflow their track.

See `CHANGELOG.md` for the full list.

## Download

Install the **Windows x64 setup executable** attached to this release. The
Microsoft WebView2 Runtime is required. `SHA256SUMS.txt` contains the installer
checksum; compare it with `Get-FileHash -Algorithm SHA256 <installer-path>`.

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. Upstream auto-updates are disabled. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
