# Swarmterm GN 1.26.0

Corporate readiness release. Several defaults are stricter; read the upgrade
notes before installing.

- **No telemetry, no updater:** the Google Analytics code and the disabled
  updater are removed. The app sends no usage data and never checks for or
  downloads updates of itself.
- **Secrets stay out of child processes:** panes, routines and every program
  Swarmterm starts get a filtered environment. **Settings → Terminal →
  Environment** offers **Hide secrets** (default), **System variables only**
  and an allow list. The setting is saved and applies to restored panes.
- **Agent permission hardening:** bypass modes (including Claude **Auto**)
  are confirmed and badged; `worktree.spawn` workers do not inherit them
  unless you allow it; War Room execute by agents is off by default; the MCP
  server requires a Bearer token, now a per-pane secret.
- **Administrator policy:** `HKLM`/`HKCU\Software\Policies\SwarmtermGN`
  values (`DisableBypassModes`, `DisableWarRoom`, `DisableWarRoomExecute`,
  `DisableMcp`, `EnvPolicy`, …) are enforced in the backend, with ADMX/ADML
  templates. See [admin-policy.md](../admin-policy.md).
- **Swarmterm GN Corp:** a second installer with its own identifier,
  per-machine install and compiled-in locks. See [editions.md](../editions.md).
- **Supply chain:** SHA-pinned actions, signed build provenance, CycloneDX
  SBOMs, `SHA256SUMS.txt` (installers and SBOMs), CodeQL, OpenSSF Scorecard, `cargo deny`,
  `npm audit signatures`, REUSE licensing.
- **Previews:** plain `http:` images no longer load in Markdown previews, and
  web preview webviews have no access to the app's IPC.
- **Documents:** privacy policy, terms of use, security policy, security
  model, enterprise deployment guide and a corporate review pack (English and
  German).

See `CHANGELOG.md` for the full list.

## Upgrade notes

- Secrets in Swarmterm's own environment no longer reach panes. If an agent
  authenticates through a variable such as `ANTHROPIC_API_KEY` or
  `OPENAI_API_KEY`, add it under **Always pass these variables**, or log in
  through the agent's own configuration.
- The first start after the upgrade uses the default filter (**Hide
  secrets**, empty allow list) until Settings saves your choice.
- War Room execute by agents is off; turn on **Settings → Terminal → Agent
  safety → Allow agents to run prompts in other panes** if you want it.
- Swarmterm GN Corp is a separate app: it does not take over the Standard
  edition's settings or saved workspaces.

## Download

Two Windows x64 setup executables are attached to this release:

- `Swarmterm.GN_1.26.0_x64-setup.exe`: Standard edition, per-user install.
- `Swarmterm.GN.Corp_1.26.0_x64-setup.exe`: Corp edition, per-machine install
  (needs administrator rights).

The Microsoft WebView2 Runtime is required.

Verify the download in PowerShell before installing:

    Get-FileHash -Algorithm SHA256 .\Swarmterm.GN_1.26.0_x64-setup.exe
    # must match the line in SHA256SUMS.txt
    gh attestation verify .\Swarmterm.GN_1.26.0_x64-setup.exe --repo apoOooh/swarmterm-gn
    # proves it was built by this repository's release workflow

The installer is not Authenticode-signed; Windows SmartScreen may show an
unknown publisher warning. The app never updates itself. Download future
GN versions from this fork's releases. macOS and Linux are not supported.
